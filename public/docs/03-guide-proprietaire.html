🏠 Guide Propriétaire / Bailleur

Pour qui : Propriétaires bailleurs ayant confié la gestion à FITAL-IMMO

Objectif : Suivre vos biens, vos loyers et vos reversements.

1. Connexion à votre espace

Étape 1 : Allez sur la plateforme FITAL-IMMO.
Étape 2 : Entrez l'email que FITAL-IMMO vous a communiqué.
Étape 3 : Entrez le mot de passe temporaire fourni.
Étape 4 : Cliquez sur Se Connecter.
💡 Première connexion : Changez immédiatement votre mot de passe via votre profil (en haut à droite).

2. Voir vos biens

Dans le menu Mes Biens, vous trouverez tous les biens que vous avez confiés à FITAL-IMMO.

Pour chaque bien, vous pouvez consulter :

  • Le statut (Occupé, Vacant, Maintenance)
  • Le locataire en place
  • Le loyer mensuel
  • L'historique des paiements

3. Suivre vos revenus

Dans le menu Mes Paiements, retrouvez tous les loyers encaissés pour vos biens.

Chaque paiement affiche :

  • La période (mois concerné)
  • Le montant du loyer
  • Le locataire
  • La date d'encaissement

4. Consulter vos reversements

Chaque mois, FITAL-IMMO vous verse le montant des loyers encaissés déduction faite de la commission de gestion.

Dans le menu Mes Reversements, vous retrouvez :

  • Le montant brut encaissé
  • La commission agence
  • Les éventuelles dépenses (travaux, réparations)
  • Le montant net qui vous est reversé
Formule : Loyers bruts − Commission agence (10%) − Travaux imputés = Montant net reversé

5. Suivre les travaux

Dans le menu Travaux, vous voyez tous les travaux effectués sur vos biens :

  • Nature du problème
  • Artisan intervenant
  • Coût estimé et coût réel
  • Imputation (propriétaire ou locataire)

6. Télécharger vos documents

Dans le menu Mes Documents, vous pouvez télécharger :

  • Les quittances de loyer
  • Les bulletins de reversement
  • Les mandats de gestion
