💵 Guide Caissier / Comptable

Pour qui : Caissier, comptable, responsable encaissement

Objectif : Encaisser les loyers, gérer la caisse et les quittances.

1. Connexion

Étape 1 : Allez sur la plateforme FITAL-IMMO.
Étape 2 : Entrez votre email et mot de passe.
Étape 3 : Cliquez sur Se Connecter.

2. Encaisser un loyer

Étape 1 : Menu Loyers → cliquez sur Enregistrer un encaissement.
Étape 2 : Sélectionnez le locataire dans la liste.
Étape 3 : Vérifiez les montants (loyer, charges, pénalités).
Étape 4 : Choisissez le mode de paiement.
Étape 5 : Cliquez sur Encaisser & Émettre Quittance.
Étape 6 : Imprimez la quittance pour le locataire.
💡 Modes de paiement disponibles :
  • Espèces : comptoir agence
  • Wave : mobile money
  • Orange Money : mobile money
  • Virement : banque
  • Chèque : bancaire

3. Gérer la caisse

Le menu Caisse vous permet de voir tous les mouvements d'espèces.

Encaissement : entrée d'argent en caisse.
Décaissement : sortie d'argent (travaux, remboursements, etc.).

4. Clôture journalière

En fin de journée, faites une clôture de caisse pour vérifier le solde.

Étape 1 : Menu Caisse → onglet Clôtures.
Étape 2 : Cliquez sur Nouvelle Clôture.
Étape 3 : Comptez les espèces en caisse.
Étape 4 : Saisissez le montant réel.
Étape 5 : Le système calcule automatiquement l'écart éventuel.
Étape 6 : Validez la clôture.
⚠️ Important : En cas d'écart, notez les observations pour justifier la différence.

5. Validation des paiements mobiles

Les paiements par Wave/Orange Money sont automatiquement en attente de validation.

Étape 1 : Menu Paiements en attente.
Étape 2 : Vérifiez la référence de transaction (Wave, OM).
Étape 3 : Si valide → cliquez sur Valider.
Étape 4 : Si suspect → cliquez sur Rejeter avec motif.

6. Imprimer une quittance

Étape 1 : Menu Loyers → trouvez le paiement.
Étape 2 : Cliquez sur Quittance.
Étape 3 : Imprimez ou enregistrez en PDF.
Étape 4 : Envoyez par WhatsApp au locataire si besoin.

7. Envoyer une quittance par WhatsApp

Étape 1 : Menu Loyers → cliquez sur l'icône WhatsApp (verte).
Étape 2 : Le message pré-rempli s'ouvre.
Étape 3 : Envoyez au locataire.

8. Bonnes pratiques

  • Enregistrez les paiements immédiatement après encaissement.
  • Vérifiez les références Wave/OM avant validation.
  • Faites la clôture chaque jour avant de quitter.
  • N'acceptez jamais un paiement sans émettre de quittance.
